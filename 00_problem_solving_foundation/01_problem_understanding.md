# Problem Understanding

## Prerequisites

Before starting LeetCode, you should know:

- Basic Python syntax
- Variables
- if / else
- for loops
- Lists
- Functions

If you are not comfortable with these, practice basic Python first.

---

## Why Problem Understanding Matters

Most beginners fail not because they don’t know algorithms.

They fail because:
- They misread the question
- They rush into coding
- They ignore edge cases
- They don’t understand constraints

Understanding the problem clearly is more important than writing code quickly.

---

## Step 1: Restate the Problem

Before coding, explain the problem in your own words.

Example:

Original:
"Given an array of integers, return the maximum value."

Your words:
"I need to look through the list and return the biggest number."

If you cannot explain it simply,
you probably don’t fully understand it.

---

## Step 2: Identify Inputs and Outputs

Ask:

- What is the input?
- What is the output?
- Can input be empty?
- Can numbers be negative?
- Are duplicates allowed?

Write it clearly before coding.

---

## Step 3: Look at Constraints

Constraints help you choose the right algorithm.

Examples:

- n <= 1000 → O(n²) might be OK
- n <= 100000 → O(n²) is too slow

Always check constraints before coding.

---

## Step 4: Think of a Simple Solution First

Start with brute force.

Do not try to be clever immediately.

Simple solution → make it correct → then improve.

---

## Step 5: Write a Small Plan

Before coding, write 3–5 steps:

Example:
1. Assume first number is max
2. Loop through the rest
3. Update max if needed
4. Return max

This prevents messy coding.

---

## Beginner Checklist

Before coding:

- [ ] I understand the problem
- [ ] I know the input and output
- [ ] I checked constraints
- [ ] I can describe the solution in steps
